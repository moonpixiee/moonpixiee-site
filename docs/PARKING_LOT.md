## The production pipeline *(every set travels it — no shortcuts)*

```
📖 Scene Manuscript  →  🎨 Visual Bible  →  🎬 Scene Direction  →  🖼 Final Render
```

We do **not** let the render be generated from the manuscript alone. Every set is handed **production-quality Scene Direction** — so if we ever remake the art in three years, with a better AI or a human concept artist, the House stays *exactly consistent.* The manuscript is the soul; the Visual Bible is the frame; the Scene Direction is the brief; the render is only an interpretation of all three.
