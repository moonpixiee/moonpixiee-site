# 🎨 The Visual Bible
### House of Luna · rooms are composited sets, not flat images

> **The Library is not one image. It is a *composited set*** — like Pixar, like a game engine, like a theatre stage. It is built from multiple images **stacked** on top of one another, each rendered separately and, crucially, **animated independently.** The sky drifts, the candles flicker, the fire pops, dust floats, the raven blinks — **without ever regenerating the room.** *(This is what we meant by "layers" from the very beginning.)*

*Companion to the Room Manuscripts. The Manuscript writes a piece's **soul**; the Visual Bible renders its **body as one layer** in the stack. Everything answers to the House Laws — above all, the Prime Law: build memories, not features.*

---

## The stack *(the Library / Threshold scene, far → near)*

| Layer | What it is | Animates as |
|---|---|---|
| **0** | 🌙 **Sky** | drifting clouds, the moon slipping behind them, a rare shooting star — **✅ built** (the living sky) |

| **4** | 🔥 **Fireplace** | the fire pops and breathes, embers rise |
| **5** | 🪑 **Furniture** | the chair, the tables — mostly still, subtly lit |
| **6** | ☕ **Objects** *(tea, books, candles, the raven)* | steam curls, candles flicker, the raven blinks |
| **7** | ✨ **Atmosphere** *(dust, embers, ghosts)* | dust in the moonbeam, ghosts rearranging shelves |
| +8 | 🔊 **Sound** *(non-visual)* | the room's own audio (fire, pages, a far ladder) |
| +9 | ⚡ **Interactions** *(non-visual)* | the invisible hotspots laid over the stack |

**The Threshold = the FINAL COMPOSITE:** `Sky + Windows + Architecture + Shelves + Fireplace + Furniture + Objects + Atmosphere` = the Threshold Scene — the room you stand in as the hub. Its "art" is **the whole stack**, never a single flat plate.

> **Each layer renders as an isolated, transparent-background asset — a game asset, not a painting.** We build an **asset pack** and the engine assembles it. This is the production method — see **`ASSET-PRODUCTION-STANDARD.md`**. (A full-scene image is *concept art / the composed target*, never a production layer.)

## Two truths that just became one

- **A manuscript is a layer's design document.** The Fireplace manuscript (№001) is the brief for **Layer 4.** The Bookshelves manuscript → **Layer 3.** The Sky → **Layer 0.** One manuscript, one layer, **one job, one masterpiece.**
- **The layers *are* the interactive zones.** The Fireplace is Layer 4 in the composite **and** Zone 1 you click into. The stack is the hub; touching a layer-object is how you navigate deeper. *(Environmental Navigation, LAW 010 — the room is the menu.)*

## The pipeline

```
📖 Manuscript  →  🎨 Layer Design  →  🖼 Layer Render (one layer, one job)  →  ⚡ Claude stacks them  →  🏡 the House comes alive
```

**No AI slop.** We never ask for *"a cozy library."* We ask for *"the Fireplace layer — at rest, transparent background, House Standard lighting."* One job. One masterpiece. This is the difference between a pile of AI images and a **handcrafted world built layer by layer** — exactly how real game studios and animated films work.

## The approval gate *(unchanged)*

> **Nothing advances to the next layer until we both say: "This is canon."** Stone by stone, not feature by feature. A layer is done only when it passes **The Memory Test** — *could someone remember this ten years from now?*

---

## ✨ The Superpower — swap a layer, not the room

Because the room is a stack, the House can **change without being regenerated.** Six months from now you want Christmas? You don't rebuild the Library — you **swap Layer 7** (snow past the windows, evergreen garland, a different candle, warmer blankets) and nudge Layer 0's weather. Done. **The House evolves without losing its soul** — the architecture and the story (the deep layers) stay constant while the surface breathes. *(This is the engine behind the parked Seasons Bible, and it's already lawful — LAW 006 the lunar cycle, and the Living-House rule, work exactly this way.)*

---

## Status of the art

This **supersedes the single-plate approach.** The room images we made before (the Conservatory, the photoreal scenes) are now **concept art** — a functional v1 — beautiful, and kept, but they were *one flat render.* The new production standard is **layered composites.** We re-render as layers, one masterpiece at a time. **Layer 0 already proves it works:** the living sky is a real, separate, independently-animated layer — not baked into any plate.

## Every layer ends with The Memory

Per the Prime Law, each layer's document closes with one line — the memory it's trying to create. *(Layer 0 — Sky: "I remember looking up from my book and realizing the moon had slipped behind the clouds." Layer 1 — Windows: "I remember standing beside the window listening to rain while everyone else in the world was asleep." One day these gather into **The Memory Book.**)*
